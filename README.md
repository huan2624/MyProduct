# 平面设计作品集网站

一个纯静态的单页作品集：**分类筛选 + 大图查看（灯箱）**，零依赖、零构建、零服务器成本。

---

## 一、怎么预览

最简单：**直接双击 `index.html`**，浏览器就能打开。
（作品列表用的是 `data/works.js` 而不是 `.json`，所以本地直接打开也能读，不需要装任何东西。）

如果想用更接近线上的方式预览（推荐）：

```powershell
cd D:\TestSite
npx serve .        # 或者： python -m http.server 5173
```

然后打开 `http://localhost:3000`。

## 二、目录结构

```
TestSite/
├─ index.html                  页面结构 + 所有文案（名字、简介、关于、联系方式）
├─ css/style.css               全部样式；顶部 :root 是颜色/圆角/字体的总开关
├─ js/main.js                  渲染、筛选、灯箱逻辑（一般不用改）
├─ data/works.js               ★ 作品列表 —— 你唯一需要经常改的文件
├─ images/works/               作品图片放这里
├─ tools/generate-placeholders.mjs   生成示例占位图（真实作品放进去后可删）
└─ README.md
```

## 三、加一个作品（最常用）

1. 把图片丢进 `images/works/`，例如 `images/works/brand-04.jpg`
2. 打开 `data/works.js`，复制一段 `{ ... }` 改内容：

```js
{
  id: 'brand-04',                      // 唯一，不能重复
  title: '新作品的名字',
  category: '品牌识别',                 // 相同分类会自动合并成筛选按钮
  year: 2026,
  src: 'images/works/brand-04.jpg',    // 网格里显示的图（压缩版）
  full: 'images/works/brand-04.jpg',   // 点开看的大图（可以和 src 相同）
  ratio: '4 / 3',                      // 网格比例，默认 4/3；宽幅大图用 8/3
  featured: false,                     // true = 在网格里占两列
  tags: ['LOGO', '包装'],
  desc: '一句话说明这个项目。',
}
```

存盘，刷新页面即可。**不用改 HTML。**

暂停/删除作品：把 `data/works.js` 里对应那段删掉就行。

## 四、图片怎么处理（重要，直接影响打开速度）

网页上不要直接放设计原稿，体积差几十倍。

| 用途 | 字段 | 建议尺寸 | 格式 |
|---|---|---|---|
| 网格缩略图 | `src` | 宽 800～1200px | WebP 或 JPG（质量 75～82） |
| 灯箱大图 | `full` | 宽 1600～2000px | WebP 或 JPG（质量 80～85） |

推荐工具（拖进去就压缩，免费）：
- <https://squoosh.app>
- <https://tinypng.com>

命名建议：`分类-序号.jpg`，如 `poster-04.jpg`，好找也好排。

> 关于 `ratio`：网格里所有作品建议**统一用 `4 / 3`**，跨列大图用 `8 / 3`，这样每行高度整齐。
> 想展示竖构图，就给它单独设 `ratio: '3 / 4'`，但要知道那一行会比其他行高一些。

## 五、改成你自己的内容

全在 `index.html` 里，搜这几个位置（都标了 `✏️`）：

| 要改什么 | 位置 |
|---|---|
| 浏览器标签标题、SEO 描述 | `<head>` 里的 `<title>` 和 `meta description` |
| 左上角名字/工作室名 | `.brand` |
| 首屏大标题、自我介绍 | `.hero` |
| 关于我、能力、工具 | `#about` |
| 邮箱和社交链接 | `#contact` |
| 版权署名 | 页脚 `site-footer` |

整体配色和圆角：改 `css/style.css` 顶部的 `:root { ... }` 变量即可。
不想要深色模式：删掉 CSS 里 `@media (prefers-color-scheme: dark)` 那一段。

## 六、上线（免费托管）

这个站是纯静态的（HTML + CSS + JS + 图片，没有后端、没有构建步骤），
所以任何静态托管都能直接放上去，**不需要服务器**。

> ⚠️ 价格和政策会变，下面标注的是 **2026 年的情况**。动手前建议再看一眼官网定价页。

### 免费托管横向对比（2026）

| 平台 | 免费额度 | 国内访问 | 适合你吗 |
|---|---|---|---|
| **EdgeOne Pages**（腾讯） | 永久免费 | ⭐ 亚洲节点 2500+，通常最好 | ✅ 首选 |
| **Cloudflare Pages** | 无限流量、500 次部署/月 | 一般，偶有波动 | ✅ 次选 |
| **GitHub Pages** | 仓库 1GB、流量 100GB/月 | ⚠️ 经常慢或打不开 | 备用 |
| **Vercel Hobby** | 流量 100GB/月 | ❌ 国内常被墙 | 不太推荐 |
| **Netlify 免费版** | ⚠️ 已改积分制：300 积分/月 | 一般 | 不推荐了 |

**关于 Netlify**：它以前是最好上手的（拖拽即上线），但免费版已改成积分制——
带宽 20 积分/GB，也就是 **300 积分大约只够 15GB 流量**，而且每次生产环境部署还扣 15 积分。
对作品集来说很容易用完，所以不再推荐。

### 推荐做法 A：EdgeOne（腾讯出品，国内访问最稳）

⚠️ **先分清两个不同的产品**，它们的免费政策不一样：

| | EdgeOne **Makers / Pages** | EdgeOne **CDN 免费套餐** |
|---|---|---|
| 地址 | pages.edgeone.ai | edgeone.ai/get-free-plan |
| 定位 | 部署网页项目（静态站 + 函数） | 纯 CDN 加速 |
| 免费政策 | 官网 FAQ 称**永久免费**、不用绑卡 | **限量内测**，需参与测速分享或兑换码 |
| 限制 | 未查到明确限制 | ⚠️ 条款限制"高比例图片"（见下） |

**对本项目来说用 Makers / Pages 更合适**（它就是给静态站用的）。

#### 备案问题（最关键的结论）

**分区不看你怎么想，看服务器在哪。** EdgeOne 自己的 ICP 指南原文：

> ICP 备案的要求是由**服务器位置**触发的，而不是您的企业位置或目标受众。
> 如果您的网站托管在**中国大陆的服务器**上，则需要进行 ICP 备案；
> 如果仅托管在**中国大陆以外**，则不需要进行 ICP 备案。

落到具体操作：

| 情况 | 是否需要备案 |
|---|---|
| 用 EdgeOne 送的默认域名（`xxx.edgeone.app`） | ❌ **不需要**（域名归腾讯，备案是它的事） |
| 绑自己的域名，只走境外节点 | ❌ 不需要 |
| 绑自己的域名，要用**中国大陆节点**加速 | ✅ **必须备案**（工信部硬性规定，任何厂商都一样） |

> 判断方法：控制台添加域名时会让你选**加速区域**。选了含中国大陆的，系统会当场校验你的域名备案状态，
> 没备案根本保存不了——准不准，控制台会直接告诉你，不用猜。

#### ⚠️ 需要注意的条款（CDN 免费套餐）

免费套餐使用说明里有一句：

> 免费套餐主要提供缓存并加速网页及网站内容的交付，**不提供视频或其他大型文件业务**
> （包括但不限于高比例图片、音视频文件，游戏安装包等）。

这条主要针对"拿免费 CDN 当图床"的用法。作品集把图片压到 200KB 级 WebP、整站几十 MB，
实际使用大概率没问题；但这是条款里写明的，你要知道存在这个风险。
真需要长期稳定，个人版约 $4.2/月（含 50GB 流量 + 300 万次请求）。

> 上面这条出自 **CDN 免费套餐**的文档。**Makers / Pages 是另一个产品**，
> 我写这份文档时 `pages.edgeone.ai` 从本机访问不通，没能读到它自己的条款，
> 所以无法确认它是否有同样的图片限制——**建议你在它的控制台确认一下再决定**。

#### 接入步骤

1. 打开 <https://pages.edgeone.ai>，注册（免费，不用绑卡）
2. 连接 Git 仓库，或直接上传文件夹
3. 纯静态项目**无需构建命令**，输出目录填根目录 `/`
4. 拿到 `xxx.edgeone.app` 地址，可绑自己的域名，自动配 HTTPS

### 推荐做法 B：Cloudflare Pages

1. 打开 <https://dash.cloudflare.com> 注册
2. Workers & Pages → Create → Pages → 上传资源（Direct Upload）或连 Git
3. 免费额度：**无限带宽**、500 次部署/月

> 注意：Cloudflare 现在把新项目往 **Workers 静态资源** 上引导，Pages 仍在正常服务。
> 这个站太简单了，两者都能放。

### 做法 C：GitHub Pages（顺手，但国内不稳）

**已实测：完全可用。** 项目站部署在子路径 `用户名.github.io/portfolio/` 下，
我把整个站放到 `/portfolio/` 子目录跑了一遍——CSS、JS、12 张图、灯箱大图全部正常加载，控制台零报错。
（本项目所有路径都是相对的，比如 `images/works/xxx.jpg`，没有用 `/images/...` 这种绝对路径，
所以放在子目录里也不会挂。这是 GitHub Pages 项目站最常见的翻车点，这里不用担心。）

**接入步骤：**

```powershell
cd D:\TestSite
git init
git add .
git commit -m "作品集上线"
git branch -M main
git remote add origin https://github.com/你的用户名/portfolio.git
git push -u origin main
```

然后进仓库 **Settings → Pages → Source** 选 `main` / `root`，
几分钟后访问 `https://你的用户名.github.io/portfolio/`。

**`.nojekyll` 已经帮你建好了**（仓库根目录那个空文件），作用是关掉 GitHub 的 Jekyll 处理。
不加它，Jekyll 会忽略所有以 `_` 或 `.` 开头的文件/目录，也会拖慢构建。现在不用管了。

**额度（软限制，一般够用）：**

| 项目 | 免费额度 |
|---|---|
| 仓库大小 | 建议 ≤ 1GB |
| 月流量 | 100GB |
| 构建次数 | 10 次/小时 |
| HTTPS | 自动签发 | 
| 自定义域名 | 支持（仓库根放一个 `CNAME` 文件，内容写你的域名） |

**注意事项：**

- 免费账号要求仓库是 **public**。别人能看到源码，但图片本来也是公开的，一般无所谓。
- 国内访问 GitHub Pages **经常很慢甚至打不开**，不适合直接发给甲方看。
- 建议把它当作「版本管理 + 备份」用，同时再往 EdgeOne / Cloudflare 放一份对外发布。

### 关于域名

免费的二级域名（`xxx.edgeone.app`、`xxx.pages.dev`、`xxx.github.io`）够用，
但发给客户显得随意。自己买域名约 **¥50～80/年**：

- 阿里云 / 腾讯云：国内注册但**必须实名**；解析到境外托管不需要备案
- Cloudflare Registrar / Namecheap / Porkbun：注册便宜，不用备案

加域名后后台会自动签发 HTTPS 证书（GitHub Pages 需要手动加 CNAME 记录）。

> **备案**是唯一的硬门槛：只要想让域名走**中国大陆节点**，就必须 ICP 备案（免费但要等 1～2 周，需要有企业/个人主体）。
> 不备案也能用，只是走境外节点，速度略慢。

### 上线后必查

- [ ] 手机上打开是否正常（滑到作品区、点开大图、左右滑动）
- [ ] 图片是否全部加载出来（有 404 会显示"图片没找到"）
- [ ] 标题和分享卡片文字是否正确（`index.html` 里的 `og:` 标签）
- [ ] 首屏速度：打开浏览器开发者工具的 Network，看总大小（建议 1MB 以内）

## 七、响应式（手机 / 平板）

断点策略：

| 视口宽度 | 栅格 | 说明 |
|---|---|---|
| ≤ 414px | 1 列 | 手机竖屏 |
| 480 ~ 768px | 2 列 | 手机横屏 / 平板竖屏 |
| ≥ 1024px | 3 列 | 桌面 |

已经实测过的项（320 / 360 / 375 / 414 / 480 / 600 / 768 / 1024 / 1440 / 1920px）：

- 全部宽度 **无横向溢出**，不会出现左右抖动
- 所有可点击元素（导航、筛选按钮、灯箱按钮、社交链接）在窄屏下 **≥ 44px**，符合触控目标最小尺寸
- 灯箱在手机上：图片四周不出界，`← →` 位置可点，**左右滑动可翻页**，下滑不足 50px 不会误触
- 卡片说明文字在窄屏自动改为上下排列，不会挤成一行

### 自己再跑一遍检查（改完样式后建议跑一次）

```powershell
node tools/serve.mjs
```

然后打开 <http://localhost:5173/tools/responsive-audit.html>，
会自动用 10 种宽度加载首页并列出：横向溢出、栅格列数、小于 44px 的触控目标。

想看单个尺寸的真实效果（含灯箱、滑动）：

<http://localhost:5173/tools/device-preview.html?w=390&h=844>
（`w` 是视口宽度，`h` 是高度，可改成 375×667、414×896、768×1024 等）

> `tools/` 目录整个都是辅助工具，**上线前可以删掉**，不影响网站运行。
